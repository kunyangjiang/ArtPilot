## 先被山抓住

几乎所有人的视线，都会先被那座大山抓住。它不在远处，而是正面、整块地立在眼前，从画面上缘一直压下来，占去了画幅的大半。

可是，“占得多”并不等于“显得大”。一张把整座山塞满取景框的照片，未必让人觉得自己渺小；山画得再满，如果我们无从判断它有多高，它也只是一块很大的形状。要感到“大”，还缺一样东西：一把尺。

<Split>
<CompositionMap artwork="art-fan-kuan-travelers-001" locator zones={[{ label: '驮队', from: 84.3, to: 94.3, left: 67.6, right: 99.7 }]} />

这幅画把尺藏在了右下角，也就是小图中框出的位置：林间的小路上，几头驮着货物的骡子和赶骡人正从树林里走出来。

它们小到几乎会被漏掉，却是画中我们最熟悉的东西。人和牲口有多大，谁都心里有数；一旦认出它们，山的高度就忽然有了单位。
</Split>

<Split reverse>
<ArtworkFigure artwork="art-fan-kuan-travelers-001" image="travelers" />

放大来看，驮队并不含糊：骡背上的货物、赶骡人的身形都交代得清清楚楚。比范宽稍晚的画家郭熙谈到仰望高山的“高远”之景时写道，其中的人物“明了”，再小也看得清。看得清，这把尺才用得上。
</Split>

尺度能解释多少，可以在下面的示意图里试一试：把人缩到最小，山确实“变高”了，可这个三角形并不因此让人感到压迫。

<ScaleSlider />

尺度回答的是“有多高”，回答不了“为什么压在眼前”。《溪山行旅图》里的山不只是高，它的分量来自另外几种手段。

## 距离被拿走了

第一种手段，藏在山与我们之间的那段空间里。

<Split>
<CompositionMap artwork="art-fan-kuan-travelers-001" zones={[
  { label: '远景：主峰', from: 2, to: 56 },
  { label: '云雾', from: 56, to: 64 },
  { label: '中景：林木、楼阁、山路', from: 64, to: 87 },
  { label: '近景：巨石', from: 87, to: 100 },
]} />

画面大致分成三段：下方的巨石，中段的林木与山路，上方的主峰。这是北宋盛行的<Term id="gl-monumental-landscape">全景式山水</Term>的典型安排。奇怪的是，三段之间并不连续。从近处的石头到中段的树林，视线还能一步步往里走；可到了树林上方，路断了，一片近乎空白的云雾把主峰和下面的一切隔开。

这片空白拿走了距离。我们无法判断树林与主峰之间隔了多远，于是主峰既不显得遥远，也没有逐渐升起的过程，而是突然、整体地立在眼前。

<Callout kind="interpretation">
“近景、中景、远景”的三段划分是现代观看的方便说法，图中比例为目测近似。
</Callout>
</Split>

北宋人对这种感受已经有了说法。郭熙的谈画之语由其子郭思整理为《林泉高致》，其中写道：

> 自山下而仰山顛，謂之高遠……高遠之勢突兀。
>
> 郭熙《林泉高致·山水訓》

“突兀”正是那种没有过渡、猛然在前的气势。<Term id="gl-high-distance">高远</Term>描述的是从山下仰望山巅的视角：画中主峰的顶端几乎贴着画框上缘，我们的视线只能向上。

<Callout kind="interpretation">
郭熙的理论晚于这幅画。用“高远”来读《溪山行旅图》，是借后来的语言描述它，而不是范宽本人的说法。
</Callout>

空间让山离我们很近，却还不能让它显得坚实。一座只有轮廓的大山，仍可能是空的。

## 山是怎样画“重”的

在缩小的全图里，主峰只是一片深色。下面四处细部，分别取自小图中编号的位置。

它们分属主峰的侧面、顶部、中景的树丛和主峰的岩面。合在一起看，可以发现画家并没有把力气平均用在每一处：最密的笔墨，集中在山体本身。
</Split>

<Band kind="notes">

<strong>1　瀑布。</strong>主峰右侧，一道极细的瀑布从暗处垂下。它几乎没有宽度，却是全画最长的一条竖线，把视线从山顶一路拉向山脚。

<strong>2　山顶。</strong>主峰顶部是由细碎墨点堆成的密林。远看只是一道轮廓，近看才知道是无数的树。这又是一把尺：树越小，山越大。

<strong>3　楼阁。</strong>中景树丛后露出几层屋檐，是画中第二处人迹。郭若虚说范宽“畫屋既質，以墨籠染，後輩目為鐵屋”：屋宇朴实厚重，后人称为“铁屋”。

<strong>4　岩面。</strong>岩壁由大量短促、近乎垂直的笔触层层叠成，常被称为<Term id="gl-raindrop-cun">雨点皴</Term>，属于<Term id="gl-cun">皴法</Term>的一种。笔触越密，石面越显得坚硬、厚重：山的分量，是一笔一笔堆出来的。

</Band>

郭若虚在《图画见闻志》里概括范宽的画风，用的正是这几种品质：

> 峯巒渾厚，勢狀雄強，搶筆俱均，人屋皆質者，范氏之作也。
>
> 郭若虛《圖畫見聞誌》卷一

“浑厚”“雄强”说的是山的分量与气势；“人屋皆质”说的是人物与房屋画得朴实、实在，与驮队和楼阁给人的感觉一致。

<Callout kind="fact">
“雨点皴”是后世对范宽笔法特点的通行称呼，并非他本人的说法；“搶筆俱均”一句的确切含义，研究者的解释不尽相同。
</Callout>

## 北宋人怎么说，我们又能确定多少

以上的判断都来自画面本身。至于画家是谁、怎样工作，只能依靠文字，而文字也有它的边界。

北宋末年宫廷编纂的《宣和画谱》记载，范宽字中立，华原人，起初师法李成，后来有所醒悟，感叹道：

> 吾與其師於人者，未若師諸物也。吾與其師於物者，未若師諸心。
>
> 《宣和畫譜》卷十一

据同一记载，他此后移居终南山、太华山的山林之间，静观云烟、风月与晴晦的变化。这段话常被当作理解《溪山行旅图》的钥匙：画中的山，不只是某一座真实的山，也是长久观看之后“心中”的山。

<Callout kind="interpretation">
这句话出自范宽身后约一个世纪的宫廷画谱，是后人的记述。用它来解释这幅具体的画，是一种读法，而不是画家留下的说明。
</Callout>

就连“这幅画出自范宽之手”，也需要证据。明代董其昌在画幅上方题写了“北宋范中立谿山行旅圖”；1958 年，台北故宫的研究人员又在画面右下、驮队后方的树丛中辨认出“范宽”二字落款。它就藏在我们最早拿来当“尺”的那片地方。这两处细节转引自二手资料，原始出版物尚待核对。

<Band kind="reflection">

回到开头的问题。

现在可以给出一个比“因为山画得很大”更完整的回答：驮队提供了尺度；云雾切断了距离，仰视让主峰突兀而至；密集的笔触让石头有了重量。这几种手段叠在一起，一座山才压到了我们眼前。

但“渺小”终究是一种感受。有些问题，画面和文献都不能替你回答：

- 如果把驮队画大一倍，这幅画会失去什么？
- 画里的山，是范宽看见的山，还是他心里的山？
- 站在一座真正的高山面前时，你的感受和看这幅画一样吗？

</Band>
